# officecli 设计规范 · 商务咨询（officecli-design-consulting）

> 来源：tencent-pptx design-principle.consulting.md（已剥离 SlideDSL / slidep / SVG 引擎依赖，只保留 officecli 可直接落地的视觉骨架）。
> 落地方式：用 `officecli add --type shape/text` 建母版与结构图，`set` 改属性，`view html/screenshot` 检查。

## 1. 风格 DNA

- Action Title 优先：正文页主标题必须是完整结论句，不能只写"市场分析"这类关键词。
- Navy 权威感：#061F32 主导全篇；颜色少、装饰少、信息强。
- 结构图优先：能用结构图讲清的内容，优先走信息结构图，不堆卡片。
- 左对齐纪律：标题、正文、图表说明默认左对齐；禁居中海报感。
- 数据+Source 可信：数据页、正文页、结构图页必须有 Source / Footnote。
- 无衬线商务感：Arial+中文黑体；禁衬线、书法、艺术字。
- 极简不是空：留白 25-40%，内容必须承担判断、论据、结论。

## 2. 母版与版面骨架

画布 1280x720；页面左右 padding 49-60。

| 区域 | 范围 | 规则 |
| :-- | :-- | :-- |
| A 页眉 | y 0-44 | 可选，仅右上 14-16px 灰色章节进度；禁彩色竖条 |
| B 标题块 | y 44 起，高度自适应 | Action Title 32-40px Bold 左对齐；顶部紧贴页面上沿（起始 y=44），禁标题上方留大段空白；单行约 60px、双行约 90px；底部 1px 黑线紧随标题底线 8-12px 作 B/C 分割。标题建议 <=2 行（<=30 字） |
| C 内容区 | 自 B/C 分割线下 12px 至 y 660 | 正文、图表、结构图、卡片；上沿跟随 B 实际底线 |
| D 页脚 | y 660-700 | 左 Source+Footnote 14-16px 灰两行；右页码 NN 14px 灰 |

省略规则：封面、章节扉页、系统标记可省 A/D；目录保留右下页码；前言、正文、模型、图表、结构图必须完整遵守。

## 3. 色彩与字体

### 色彩
| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| Navy 主色 | #061F32 / #062032 | 章节底、主框架、重点色块 |
| 皇家蓝 | #001965 | 图表第二蓝、层级色 |
| Cyan | #08A6F6 | 关键点缀、客户/重点标记；单页 <=5% |
| 浅蓝 | #99BDED | 图表第三档、辅助色阶 |
| 暗红 | #5A0E13 | 涨色/警示，仅数据或风险 |
| 绿色 | #177B57 | 跌色，仅数据涨跌 |
| 橙色 | #F47B39 | 中等风险，少量 |
| 中性灰 | #E7E6E6 / #808080 / #44546A | 表底、脚注、边框 |
| 背景 | #FFFFFF | 内页主底 |

配色比：Navy 系 20-35%，白底 >=50%，中性灰 <=15%，强调色合计 <=8%。禁金色、中国正红、朱砂红、紫粉黄品红、彩虹色、阴影、发光、3D。

### 字体
字体家族：Arial, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif。

| 层级 | px | 字重 | 用途 |
| :-- | :-- | :-- | :-- |
| 章节编号巨字 | 160-320 | Bold | 仅章节扉页 |
| 封面主标 | 60-96 | Bold | 封面 |
| KPI 大数 | 72-120 | Bold | 数据页 |
| Action Title | 32-40 | Bold | B 区固定 |
| 副标/卡片小标 | 24-30 | Bold | 次级标题 |
| 正文 | 22-28 | Regular | 段落（硬下限 >=22px） |
| 数据标签 | 16-18 | Regular | 图表标签 |
| Source/Footnote/页码 | 14-16 | Regular | 页脚 |

单页字号种类 <=5（章节扉页除外）；正文硬下限 >=22px；相邻层级字号差 >=6px。

## 4. 信息密度与可读性

| 类型 | 下限 |
| :-- | :-- |
| 封面 | 主标+副标+公司名/Logo+时间，>=20 字 |
| 目录 | 3-8 条，每条编号、章节名、摘要，总字数 >=80 |
| 章节扉页 | 巨字编号+章节标题+英文副标，>=14 字 |
| 执行摘要 | 三栏 Context/Complication/Resolution，>=160 字 |
| 单主题 | 正文+主视觉，>=120 字，图 >=30% |
| 卡片组 | 每卡 >=40 字，3 卡合计 >=120 |
| 思维模型 | 模型名+所有维度，>=160 字 |
| 数据图表 | 主图 >=50%，洞察 50-90 字 |
| 信息结构图 | 结构图 >=70% C 区+Source |

大字优先：正文字号下限优先级 > 字数下限；塞不下时精简文案、合并页面，而非缩小字号。

可读性：对比度 >=4.5:1；浅灰底用黑字或 Navy 字；Cyan 底禁白字；卡片填充率 >=75%；卡尾 y 差 <=16px。正文行高 1.4-1.5。

## 5. 配图与视觉元素

### 配图（officecli：引用本地图片或生成图元）
| 等级 | 用途 | 规则 |
| :-- | :-- | :-- |
| L1 主视觉 | 摄影或数据可视化 | C 区 >=40%；全篇二选一，不混用 |
| L2 支撑图/icon | 卡片头、流程节点 | 图 >=280x180；icon 24-48px |
| L3 母版徽标 | 统一角标 | <=64x64，仅 D 区左下 logo 位 |

L1 二选一：A 摄影类（去饱和 Navy 冷调）；B 数据可视化类（图表+线性 icon）。禁插画、3D、合成海报、红金图、城市落日实景。

Icon：仅线性单色，1.5-2px 描边，Navy 或 Cyan；禁彩色填充、emoji、渐变、卡通。

## 6. 页面类型规则

### ① 封面
满 Navy 底，或白底+Navy 主色块占左 1/3-1/2。主标 60-96px Bold 左对齐；副标紧贴主标下方。必备：主标、副标、公司/Logo、时间/版本；禁满版照片、金红剪影、烟火飘带、居中海报、巨字水印。

### ② 目录
纯白底；主标左上 26-32px Bold Navy。3-4 项单行 N 列；5-6 项 2x3；7+ 项 2x4。条目=大编号+章节名+摘要；禁圆球编号、书法繁体、单列大目录。

### ③ 章节扉页
满铺 #062032；左侧 160-320px 低透明白色巨字编号。右侧章节标题 40-48px 白字，英文副标 20px 浅灰。禁图片、渐变、金色、Cyan、装饰线、章节页码。

### ④ 执行摘要
纯白底+Navy 标题+三栏并列。三栏：Context/Complication/Resolution，每栏 80-120 字。可用 0.5px 分隔线和 2px Navy 顶线/竖条；顶线/竖条必须紧贴栏标题（间距 <=8px），不得悬空留大片空白方框。禁图标矩阵、首字下沉、引文装饰。

### ⑤ 正文
- 5a 三栏卡：3 卡水平并列，icon+标题+正文，每卡 >=60 字。
- 5b 四/六栏小卡：只放 icon、标题、短说明。
- 5c 时间轴：横向 4-6 步，1px Navy 主线+统一节点。
- 5d 大图配文：图 50-60%，右侧 3 Bullet+数据。
- 5e KPI：4 个 KPI 卡，大数字+单位+同比+一句说明。
- 5g 对比 VS：左右对照，禁红绿装饰对比。
- 5h 关键词矩阵：2x2/3x3，细灰线分隔。
- 5i 综合复杂：战略地图/实施计划/多栏复合；若核心是结构图，改走 ⑨。

卡片排布纪律（强约束）：
- 卡数必须与列数匹配，禁止末行残缺留坑（如 5 卡排 3 列 -> 3+2 缺 1，不允许）。3/6/9 卡->3 列；4/8 卡->4 列；5 卡改 5 列单行、或 2+3、或合并/拆成 4 或 6 卡。
- 末行不满时：补内容凑满整行，或调列数让各行等宽，或横向拉宽余卡占满。
- 同组卡片等宽等高，行间 gutter 统一，多行左右边界对齐。

正文页必须：完整母版、Action Title、Source、Footnote、页码；装饰只允许浅灰线、Navy 上边框/竖条、线性 icon。装饰性竖条/上边框必须紧贴所修饰标题/内容（间距 <=8px），禁悬空留空白带。

C 区整体撑满（强约束）：正文页所有内容累计高度填满 C 区可用高度 >=85%，纵向不得只占上半部；内容不足时增大卡片高度并补内容、增大行距卡距均匀铺满、或减页合并；禁"内容挤在上半、下半空荡"。

### ⑥ 思维模型
同一视觉模板成套；模型名+中央示意图+右侧维度说明。单色阶 Navy 4-5 阶；线条 1-2px；禁彩虹、纹理、3D。

### ⑦ 数据图表
白名单：柱、折、瀑布、散点、树状、Mekko、2x2 矩阵。黑名单：立体饼、立体柱、3D 散点、雷达、螺旋。必备：Action Title、主图 >=50%、洞察 80-150 字、Source/Footnote、单位标注。

### ⑧ 系统标记
母版省略；白底灰字一行；交付前删除。

### ⑨ 信息结构图
咨询风核心，建议占全篇 >=20%。结构图占 C 区 >=70%，标题必须陈述结构图结论。节点形状：矩形、圆角矩形（<=4px）、圆、椭圆、三角、箭头、chevron、平行四边形、梯形。线条：直线或直角折线；主框架 1-2px，分支 0.5-1px。配色 Navy 单色阶+少量 Cyan；禁彩虹、阴影、3D、装饰背景。字号：节点标题 22-28px Bold，说明 16-18px，标签 14-15px。

常用子版式（officecli 用 shape+text 手工搭建）：
- 9a 战略房屋：上小下大 5 层（屋顶=使命愿景；横梁=战略目标/举措；柱=支柱；地基=赋能因素），5 层 Navy 阶。
- 9b 2x2 矩阵/BCG：800x400 主区+横纵轴标"低->高"15px 灰+4 象限浅灰底+数据点圆 16-40px Navy 实心+标签 15px；客户公司用 Cyan 圆点加粗。
- 9c Issue Tree：左 1 核心问题框 120x60 -> 直角折线向右分 2-4 级；节点 120-160x50-70 1px Navy 边框白底；每层"MECE" 14px 灰；必须从左向右扩展。
- 9d 价值链：横向 5-7 个 chevron 首尾相连占宽 >=85%；客户参与节 Cyan 高亮；尾节右指尾箭头。
- 9e 流程图：横向 4-6 步矩形+标题+说明+编号；直角箭头 1.5-2px Navy。
- 9f 桥图/瀑布：首末 Navy 实心全高柱，中间浮空柱（涨暗红/跌绿）；柱顶数字和单位。
- 9g Mekko：800x400 横切 3-6 列（列宽=细分占比）+每列纵切 N 块（块高=公司份额）；全宽=100%。
- 9h 甘特/路线图：左 1/3 举措信息卡 3 列 x N 行格线；右 2/3 甘特条+时间轴。
- 9i 多支柱网格：3 列（每列 1 支柱）x 多行（每行 1 举措）；列间浅灰竖线。
- 9j 散点/气泡：800x400 坐标，数据点圆 12-60px Navy 半透明 60%；客户公司 Cyan 实心加粗。
- 9k 漏斗：垂直 4-6 层梯形上宽下窄；Nav 阶顶最深底最浅。
- 9l 组织/利益相关方：中央核心圆 Navy 实心白字 >=100x60+周围 4-8 外环节点+1px Navy 单向箭头。

## 7. 最终硬闸门

出现任一情况必须返工：
1. 正文页 Action Title 不是完整结论句，或 <=8 字关键词。
2. 5/6/7/9 缺 Source/Footnote/右下页码。
3. B/C 分割线缺失、非 1px 黑线；B 区起始 y 不统一（应=44）；标题上方留大段空白（距上沿 >48px）；分割线未紧随标题底线（间距 >16px）。
4. 字体不是 Arial+中文黑体，或出现衬线/书法/PNG 字图。
5. 配色超出 Navy/皇家蓝/Cyan/警示色+中性灰范围。
6. 金色、朱砂红、中国正红、紫粉黄品红、彩虹色出现。
7. 单页字号种类 >5，或正文 <22px，或相邻层级字号差 <6px。
8. 文字对比度 <4.5:1。
9. L1 摄影与数据可视化混用。
10. 结构图可用却堆卡片；全篇 9 占比明显不足。
11. 9 使用曲线连接、非白名单形状。
12. 图表出现 3D、雷达、螺旋或装饰背景。
13. 任意页字数低于下限 70%。
14. 占位文未清零。
15. 装饰性竖条/上边框/顶线悬空，与所修饰标题/内容间距 >8px，形成"短线+空方框+文字"脱节。
16. 卡片组末行残缺留坑，或同组卡不等宽等高/多行边界不对齐。
17. 正文页内容未撑满 C 区（累计高 <85%），下半部留白；或左右两栏底部悬殊。
